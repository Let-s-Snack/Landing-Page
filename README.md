# Landing-Page

![WhatsApp_Image_2024-10-17_at_11 -removebg-preview](https://github.com/user-attachments/assets/a4eec270-fbb3-4c16-b204-4ec2ccb3787e)

A landing page é uma página web dedicada e projetada para mostrar e promover o nosso produto, o Let's Snack. Nesta, o usuário poderá conhecer um pouco mais sobre a história da nossa empresa, a Socialment, e o que o nosso aplicativo visa promover. Os administradores também terão acesso a uma página feita especialmente para eles e é na landing page que será disponibilizado o acesso a área restrita.
